# LAST LOG : 마지막 접속

2010 년대 인터넷 단체 채팅방을 배경으로 한 **협동 라이브 추리 게임**. 최대 12 명이 방 코드 하나로 같은 사건에 들어와, NPC 취조는 각자 나눠 맡고 단서·수첩·추리 보드·그룹채팅은 실시간으로 함께 쓴다. 1989 년식 CRT 모니터 바탕화면 컨셉. 모든 대사는 미리 작성된 키워드 반응형(실시간 AI 없음).

## 플레이 흐름

1. **로비** — 닉네임 입력 → "새 방 만들기"(방장) 또는 6 자리 방 코드로 "참가". 탭 하나가 플레이어 한 명이다.
2. **moi.net** — 그룹채팅은 진짜 채팅: 플레이어끼리 대화하고, NPC(고니·계룡맛·오이오이·wkwkdfoq·호호19·포청천)가 키워드에 끼어들며, 조건이 맞으면 이벤트가 터진다. 닉네임을 입력하면 그 NPC와의 **1:1 취조**로 전환된다(취조 기록은 본인만 봄).
3. **공유 단서** — 누가 무엇을 알아내든 즉시 방 수첩에 기록되고 그룹채팅에 "📎 ○○ — 단서 제목"으로 뜬다. **신뢰도는 방 단위**: 남이 알아낸 사실이 내 취조의 잠금을 푼다.
4. **증거 제시** — 1:1 취조 아래 메뉴에서 방 수첩의 단서를 골라 상대에게 보여 준다. 전용 반응 + 새 단서.
5. **검색** — 키워드로 기록 조사. 결과가 전부 사실은 아니다(가짜 단서 8 개, 관련자에게 제시하면 반박됨).
6. **추리 보드** — Obra Dinn + Golden Idol 방식의 **공유 보드**. 날마다 빈칸 문장 5~7 개가 있고, 빈칸에 끼울 **조각은 방 수첩에 단서가 모일 때만 생긴다** (인물 이름만 처음부터 있음). 누군가 단서를 찾으면 채팅에 "🧩 새 조각: 23:18 (에이)"가 뜨고 모두의 조각 트레이에 나타난다. 조각을 누르면 빈칸에 끼워지고(칸을 먼저 누르면 그 칸에), 누가 끼웠는지 표시되며 실시간 공유된다. 가짜 단서도 조각을 만든다("해커", "승합차 운전자"). "확인"은 어느 칸이 틀렸는지 알려 주지 않고, 맞은 칸이 3 개 이상 동시에 있어야 잠긴다. 보드를 다 잠그면 정리 단서 + 그룹채팅 반응.
7. **다음 날** — 그날 보드가 완성되면 **방장**이 `오늘은 여기까지`로 넘긴다(방장이 2 분 이상 자리를 비우면 누구나 가능). DAY 5까지.
8. **최종 추리** — 8 칸짜리 마지막 보드. 방 전체가 함께 완성하면 결말. 데미안의 예약 게시물까지 열었으면 TRUE END, 찾은 가짜 단서를 전부 반박했으면 PERFECT.

채팅창 명령어: `닉네임`, `그룹채팅`, `검색 ○○`, `증거 ○○`, `목표`, `힌트`, `정리해줘`, `방 정보`, `나가기`, `오늘은 여기까지`.

## 구조

- `index.html` / `style.css` — CRT 데스크톱 UI + 로비
- `data.js` — 게임 데이터: NPC 대사 540 개, 검색 단서 50 + 가짜 8, 증거 반응 ~150, 그룹 반응/이벤트, 추리 보드 5 개, 미해결 의문
- `script.js` — 게임 로직 + 방/동기화 (전부 브라우저에서 동작)
- `store.js` — 동기화 계층. Firebase Realtime Database가 있으면 그걸 쓰고, 없으면 같은 브라우저 탭끼리만 동기화되는 로컬 모드
- `database.rules.json` — Realtime Database 보안 규칙 (`rooms/<코드>` 아래만 읽기/쓰기 허용)

## 배포 / 설정

Hosting은 `main`에 push하면 GitHub Actions가 자동 배포한다. **여러 기기에서 같은 방에 들어오려면 딱 한 가지 설정이 필요하다** (브라우저에서만):

1. Firebase 콘솔 → 프로젝트 `moi-net` → 빌드 → **Realtime Database** → "데이터베이스 만들기" → 위치는 아무거나(예: 싱가포르) → **테스트 모드**로 시작.
2. 끝. 다음 push부터 GitHub Actions가 `database.rules.json`을 자동 배포해 테스트 모드 규칙을 대체한다. (이미 push된 상태라면 GitHub → Actions 탭에서 최근 워크플로 "Re-run all jobs".)

설정 전에는 사이트 로비에 "로컬 모드"라고 표시되고, 같은 브라우저의 탭끼리만 동기화된다. 설정 후에는 "실시간 서버 연결됨"으로 바뀐다. Firebase 설정값(apiKey 등)은 Hosting이 자동으로 제공하는 `/__/firebase/init.js`에서 받아오므로 코드에 붙여 넣을 것이 없다. Spark(무료) 플랜으로 충분하다.

## 로컬에서 보기

```bash
python3 -m http.server 8080
```

로컬에서는 Firebase 스크립트가 없으므로 로컬 모드로 뜬다. 탭을 두 개 열면 두 명으로 테스트할 수 있다.
