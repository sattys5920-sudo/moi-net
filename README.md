# LAST LOG : 마지막 접속

2010년대 인터넷 단체 채팅방을 배경으로 한 텍스트 기반 실종 추리 게임. 1989년식 CRT 모니터 바탕화면 컨셉으로 감싸져 있다. 모든 대사는 미리 작성되어 있으며, 플레이어가 특정 키워드를 입력하면 그에 맞는 반응이 나오는 방식이다 (실시간 AI 응답 없음 — 추가 비용이나 설정이 필요 없다).

- **moi.net** — "새벽 2시" 채팅방. 그룹채팅과 6명(고니·계룡맛·오이오이·wkwkdfoq·호호19·포청천)과의 1:1 채팅을 오갈 수 있다. 닉네임만 입력하면 그 NPC와의 대화로 전환된다. 관련 키워드를 입력하면 숨겨진 사실이 하나씩 드러난다.
- **검색** — 키워드로 조사. 구체적인 키워드일수록 더 깊은 단서가 나온다.
- **단서 수첩** — 지금까지 대화·검색으로 알아낸 단서를 자동으로 모아 보여준다.
- **최종 추리** — 5가지 질문에 객관식으로 답하면 즉시 채점되고 진실이 공개된다.
- 채팅창에서 `오늘은 여기까지`라고 입력하면 다음 날(최대 DAY 5)로 넘어가며, 날짜가 지날수록 더 깊은 키워드 반응이 열린다. `힌트`, `정리해줘`, `검색 ○○○`도 채팅창에서 바로 입력 가능.

## 구조

- `index.html` / `style.css` — CRT 데스크톱 UI
- `data.js` — 게임 데이터: NPC별 키워드-대사, 검색 단서, 최종 추리 문제와 정답, 진실 텍스트
- `script.js` — 게임 로직 (키워드 매칭, 날짜 진행, 단서 수첩, 최종 채점) — 전부 브라우저에서 동작

## 배포

이 저장소는 GitHub Actions로 Firebase Hosting에 연결되어 있다. `main` 브랜치에 push하면 자동으로 배포된다. 별도 서버나 API 키, 유료 요금제가 필요 없다.
