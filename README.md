# LAST LOG : 마지막 접속

2010 년대 인터넷 단체 채팅방을 배경으로 한 텍스트 기반 실종 추리 게임. 1989 년식 CRT 모니터 바탕화면 컨셉으로 감싸져 있다. 모든 대사는 미리 작성되어 있으며, 플레이어가 특정 키워드를 입력하면 그에 맞는 반응이 나오는 방식이다 (실시간 AI 응답 없음 — 추가 비용이나 설정이 필요 없다).

- **moi.net** — "새벽 2 시" 채팅방. 그룹채팅과 6 명(고니·계룡맛·오이오이·wkwkdfoq·호호19·포청천)과의 1:1 채팅을 오갈 수 있다. 닉네임만 입력하면 그 NPC와의 대화로 전환된다. 관련 키워드를 입력하면 숨겨진 사실이 하나씩 드러난다.
- **증거 제시** — 1:1 채팅 아래 메뉴에서 수첩의 단서를 골라 상대에게 보여 줄 수 있다. 단서에 맞는 전용 반응이 나오고, 새 단서가 열리기도 한다 (검색 → 수첩 → 제시 → 새 단서 → 다른 사람에게 제시 …).
- **검색** — 키워드로 조사. 결과 아래 연관 검색어를 따라가면 더 깊은 기록이 나온다.
- **단서 수첩** — 미해결 의문 체크리스트, 오늘 목표, 지금까지 모은 단서.
- **추리 보드** — Obra Dinn 방식. 날마다 빈칸 문장 5~7 개("데미안이 마지막 글을 남긴 시각은 [ ]이다")를 선택지로 채운다. 어느 칸이 틀렸는지는 알려 주지 않고 "틀린 칸 N 개"만 보여 주며, **맞은 칸이 3 개 이상 동시에 있어야 그 칸들이 잠긴다**(찍어 맞히기 방지). 보드를 다 잠그면 정리 단서 + 그룹채팅 반응 + 다음 날 해금.
- **최종 추리** — 8 칸짜리 마지막 보드. 다 잠그면 진실이 공개된다. 데미안의 예약 게시물까지 열었으면 TRUE END.

### 진행 규칙

- **그날의 추리 보드를 완성해야** `오늘은 여기까지`로 다음 날(최대 DAY 5)에 갈 수 있다. 목표 체크리스트는 "권장 조사"로 남아 있고(`목표`), 강제는 아니다.
- **신뢰도** = 그 사람에게서 새로 알아낸 사실의 개수. 같은 말을 반복해도 오르지 않는다.
- DAY 4 고백은 신뢰도 8 + 특정 증거(예: 23:52 댓글 기록)가 있어야 열리고, DAY 5는 신뢰도 12 + 그 사람의 DAY 4 고백을 3 개 이상 들어야 열린다.
- 키워드는 맞는데 조건이 부족하면 NPC가 "아직 못 하겠어" / "근거 있으면 보여 줘" 식으로 방향을 알려 준다.
- 같은 키워드에 더 깊은 대사가 있으면 날짜·신뢰도에 따라 자동으로 더 깊은 대답이 나온다.
- 그룹채팅은 키워드에 여러 명이 동시에 반응하고, 조건이 맞으면 이벤트(DAY 2 데미안 계정 등장, DAY 5 예약 게시물 등)가 발생한다.
- **검색 결과가 전부 사실은 아니다.** 그럴듯한 가짜 기록 8 개가 섞여 있고, 각각 최종 추리의 특정 오답을 뒷받침한다. 관련자에게 제시하면 반박 단서가 열리고 수첩에 "✘ 반박됨"으로 표시된다. 진짜 기록과 모순되는 경우도 있다. 채점 때 어떤 가짜에 속았는지 알려 주며, TRUE END에 더해 찾은 가짜를 전부 반박하면 PERFECT.
- 채팅창 명령어: `닉네임`, `그룹채팅`, `검색 ○○`, `증거 ○○`, `목표`, `힌트`, `정리해줘`, `오늘은 여기까지`.

## 구조

- `index.html` / `style.css` — CRT 데스크톱 UI
- `data.js` — 게임 데이터: NPC별 키워드-대사(540개), 검색 단서(50개), 증거 제시 반응, 그룹 반응/이벤트, 일일 목표, 미해결 의문, 최종 추리 문제
- `script.js` — 게임 로직 (키워드 매칭·조건 판정, 증거 제시, 날짜 진행, 그룹 이벤트, 단서 수첩, 최종 채점) — 전부 브라우저에서 동작

## 배포

이 저장소는 GitHub Actions로 Firebase Hosting에 연결되어 있다. `main` 브랜치에 push하면 자동으로 배포된다. 별도 서버나 API 키, 유료 요금제가 필요 없다.
